# Aplicação 1 - Factory Method para Notificações

Projeto em Java que implementa o padrão de projeto **Factory Method** para envio de notificações por diferentes canais.

## Canais implementados
- E-mail
- SMS
- Push Notification

## Como executar
```bash
mvn compile
mvn exec:java -Dexec.mainClass="app.Main"
```

Ou compile manualmente:
```bash
javac -d out src/main/java/notificacoes/*.java src/main/java/app/Main.java
java -cp out app.Main
```
